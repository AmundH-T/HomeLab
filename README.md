# HomeLab

Personal homelab project built around an old Lenovo ThinkBook 14 G2 ITL.

## Goal

The goal of this project is to build and operate a small home server while developing practical skills in:

* Linux
* Networking
* Docker
* Git and GitHub
* Databases
* APIs
* Monitoring
* Distributed systems

The server will initially be used for a Minecraft server. Later, the project will be expanded but this is a way for me to learn servers
## Hardware

* Lenovo ThinkBook 14 G2 ITL
* Intel Core i5-1135G7
* 8 GB DDR4 RAM
* 256 GB NVMe SSD
* Intel Wi-Fi 6 AX201
* Realtek PCIe GbE Ethernet
